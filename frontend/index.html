How it holds up

Client

  • The button locks on the first click, so duplicate requests never leave the browser.
  • Fonts, images and scripts are self-hosted and cached at the NGINX edge, well under 200 KB in total.
  • Status arrives over Server-Sent Events, with polling as a fallback.

Gateway and app

  • NGINX spreads traffic across three stateless replicas and rate-limits each IP.
  • A Redis Lua script checks and decrements stock in one atomic step.
  • Granted claims return 202 Accepted with a tracking URL, and go onto a Redis Stream.

Data

  • Workers drain the stream in micro-batches into a shared Postgres.
  • Each write is conditional: stock > 0 inside a transaction, so the database can't oversell either.
